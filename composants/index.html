Les composants du site

La seconde barre insère les composants DSFR. La case Barre des composants, en bas du menu Insérer, l'affiche ou la masque (le choix est retenu). Survolez un composant puis cliquez Modifier, ou double-cliquez son titre, pour changer son titre et ses options. Le contenu se modifie directement.

Vidéo

Vidéo, dans le menu Insérer, insère une vidéo : Parcourir… choisit un fichier MP4 de l'ordinateur, copié dans le dossier videos à côté du document (au premier enregistrement pour un nouveau document). Ajoutez un titre, des sous-titres .vtt si possible (accessibilité) et une image d'affiche. La vidéo se lit dans l'éditeur, dans l'affichage Diapos et en plein écran avec Présenter ; sur le site, avec le lecteur du DSFR. Le format MP4 (H.264) se lit sur Mac comme sur Windows.

Diagrammes (Mermaid)

Diagramme, dans le menu Insérer, ouvre l'éditeur de diagrammes : code à gauche, aperçu à droite, modèles (organigramme, séquence, Gantt, carte mentale…), sens et placement des organigrammes. Les diagrammes prennent les couleurs du Système de design de l'État (palettes de DSFR Chart) ; le menu Thème propose aussi une version bleue, neutre ou divergente. Pour un organigramme, cliquez une forme ou une flèche dans l'aperçu pour changer son texte, sa forme ou ses couleurs, et glissez le rond ＋ d'une forme pour la relier à une autre ou en créer une nouvelle. Renseignez le titre et la description du diagramme, rubrique Accessibilité : ils deviennent le texte alternatif de l'image, et une description complète est ajoutée sous le diagramme dans les exports.

Dans le fichier, le diagramme reste un bloc de code mermaid, lisible aussi sur GitLab.

Graphiques (DSFR Chart)

Graphique, dans le menu Insérer, crée un graphique aux couleurs du Système de design de l'État : barres, courbes, camembert, étoile, nuage de points, jauge ou carte de France. Collez vos données depuis un tableur, donnez un titre et une source : le tableau des données est ajouté automatiquement, pour les personnes qui ne voient pas le graphique.

Dans le fichier, le graphique est écrit dans le format de DSFR Chart : le site l'affiche s'il charge la bibliothèque.

Pour une carte, choisissez le type Carte de France, puis le découpage : départements ou régions. Le bouton Lister tous les territoires remplit le tableau avec chaque territoire (code et nom) : il reste à saisir les valeurs. Vous pouvez aussi coller deux colonnes depuis un tableur : le territoire (code « 13 », nom « Bouches-du-Rhône » ou code de région « IDF ») et la valeur ; le titre de la seconde colonne devient le nom de l'indicateur. La valeur pour la France entière s'affiche à côté de la carte. Les outre-mer (Guadeloupe, Martinique, Guyane, La Réunion, Mayotte) sont dessinés sous la métropole. Renseignez tous les territoires : ceux sans valeur gardent la couleur de base.
