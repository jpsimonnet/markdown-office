Faire un site web

Markdown office génère un site web aux couleurs de l'État (Système de design de l'État) à partir de pages Markdown, sans MkDocs : le résultat, dans le dossier www, se publie tel quel sur n'importe quel hébergement de pages statiques.

Un site, c'est un dossier

  • site-config.md : les réglages, en métadonnées (nom du site, ministère du bloc Marianne, logo, adresse publique, langue, description, liens de l'en-tête). Il remplace mkdocs.yml ; c'est sa présence qui fait reconnaître le dossier comme un site.
  • site-accueil.md : la page d'accueil (elle deviendra index.html).
  • site-menu.md : le menu, une liste à puces de liens vers les pages ; une ligne sans lien est une rubrique, les liens en retrait sont ses pages.
  • site-footer.md (ou site-pied-de-page.md) : le pied de page.
  • les pages .md, à côté de ces fichiers. Métadonnées possibles : titre, description, gabarit (article par défaut, accueil, rubrique, pleine-largeur, diaporama), menu (libellé dans le menu) et ordre.
  • images/ : un dossier par premier mot du nom des pages : visio.md et visio-reunion.md rangent leurs images dans images/visio/ (métadonnée images pour choisir un autre dossier).
  • www/ : le site généré, entièrement refait à chaque génération (n'y modifiez rien à la main).
  • redirections (dans site-config.md) : anciennes adresses qui renvoient vers une page, une ligne - ancienne-adresse: page.md par redirection (reprises de .gitlab/redirects.yml à l'import d'un site MkDocs).

Créer ou importer un site

  • Nouveau site (accueil de l'onglet Site) demande le nom du site et le texte du ministère, puis le dossier où le créer : un sous-dossier est créé avec les quatre fichiers site-, une page d'exemple et son image, des pages Mentions légales et Accessibilité à compléter. La page d'accueil s'ouvre.
  • Importer un site MkDocs (accueil de l'onglet Site) convertit une copie d'un site mkdocs-dsfr : choisissez le dossier qui contient home.md et les pages ; le site converti est créé à côté, l'original n'est pas modifié. home.md devient site-accueil.md, _sidebar.md devient site-menu.md, les liens entre pages deviennent page.md, les images sont rangées par page (celles qui ne servent pas vont dans images/non-utilisees/), sidemenu: false devient gabarit: pleine-largeur. Un compte rendu s'affiche ; site-config.md reste à compléter, mkdocs.yml ne faisant pas partie du dossier.
  • L'espace Site a sa barre : Nouvelle page, Aperçu en direct, Publier…, puis Générer le site, Rapport avant publication, Organiser le menu et Rechercher dans le site. Sans site ouvert, elle propose Ouvrir un site…, Nouveau site et Importer un site MkDocs. Le panneau Fichiers montre le nom du site, ses pages et ses remarques.

Écrire un site

  • Affichage Site (à droite de Diapos, présent seulement pour une page d'un dossier de site) : la page telle qu'elle sera sur le site, avec l'en-tête, le menu, le fil d'Ariane et le pied de page, à côté du texte ; l'aperçu suit la frappe. Sa barre propose Pleine largeur (le texte est masqué, l'aperçu prend toute la fenêtre ; un nouveau clic revient au côte à côte) et la largeur d'écran : Ordinateur, Tablette (768 pixels) ou Mobile (375 pixels), pour vérifier le site sur téléphone. Les liens n'y sont pas suivis ; les pictogrammes des tuiles n'y apparaissent pas (ils sont bien sur le site généré).
  • Gabarit : la barre des métadonnées, en haut de la page, a une liste Gabarit (article, accueil, rubrique, pleine-largeur, diaporama) qui écrit la métadonnée gabarit ; la valeur par défaut retire la ligne.
  • Panneau Fichiers en mode site : les fichiers du site (accueil, menu, pied de page, réglages) en tête, puis les pages dans l'ordre du menu, rubriques comprises, puis les pages hors menu, en gris. Un lien du menu vers une page absente est barré. Le bouton à côté du nom du dossier passe à la vue dossier (tous les fichiers) et revient à la vue site.
  • Images : dans un dossier de site, le bouton Image, le collage ou le glisser rangent l'image dans images/ suivi du premier mot du nom de la page (visio-reunion.md → images/visio/).

Générer le site

Dans la barre de l'espace Site, le bouton Générer le site : le document en cours est enregistré, puis le dossier www est produit à côté des pages.

  • site-accueil.md devient index.html ; chaque page nom.md devient un dossier nom/index.html, comme avec MkDocs : l'adresse en ligne reste /nom/, et les anciens liens publiés continuent de marcher. Les liens page.md deviennent des liens relatifs (../page/index.html), qui marchent en ligne comme en ouvrant les fichiers depuis le disque. Une page ne peut pas s'appeler dsfr, images, mermaid ni dsfr-chart (dossiers du site généré).

  • En-tête : bloc Marianne (texte ministere), nom et slogan du site, liens d'accès rapide (liens), et le menu de site-menu.md (une rubrique s'ouvre en menu déroulant).

  • Gabarit article (par défaut) : fil d'Ariane, menu latéral avec les pages de la rubrique (la page en cours ouverte sur ses intertitres), sommaire à droite sur les grands écrans, pages précédente et suivante dans l'ordre du menu, date de mise à jour (maj).

  • Gabarit accueil (site-accueil.md) : sans menu latéral ni fil d'Ariane, pour les cartes et les tuiles. Gabarit pleine-largeur : un article sans menu latéral.

  • Les composants (cartes, tuiles, grilles, alertes, mises en avant, accordéons, citations, badges, vidéos), les tableaux, les images (largeur et alignement) et le bandeau d'information (notice) prennent le balisage du DSFR, comme avec mkdocs-dsfr.

  • Pied de page : le texte de site-footer.md, ses liens en bas de page, et le bouton Paramètres d'affichage (thème clair ou sombre).

  • Sont recopiés : le DSFR (styles, icônes, polices Marianne), les images utilisées, DSFR Chart et Mermaid si une page contient un graphique ou un diagramme (les diagrammes sont dessinés par le navigateur).

  • À la fin, un compte rendu (le même que le Rapport avant publication, voir plus bas) donne l'accessibilité de chaque page (les points du bouton Accessibilité : titre, titres, images, tableaux, liens…), les liens cassés et les images manquantes ; un clic sur une ligne ouvre la page concernée. Il signale aussi les liens mal formés (par exemple [texte]https://… sans parenthèse, ou une parenthèse de lien non refermée) : un clic ouvre la page en Côte à côte, sur la ligne à corriger. Il propose aussi d'ouvrir le site dans le navigateur.

  • Gabarit rubrique : l'introduction de la page, puis une carte par page de la rubrique, d'après site-menu.md (les pages placées sous elle dans le menu, sinon les autres pages de sa rubrique), avec leur description ou le début de leur texte.

  • Gabarit diaporama : la page est découpée en diapositives à chaque séparateur (---), comme l'affichage Diapos ; boutons Précédente et Suivante, flèches du clavier, plein écran. Sans JavaScript, les diapos se suivent.

  • Recherche : un champ dans l'en-tête de chaque page ; les résultats (page et intertitre, extrait avec les mots trouvés) s'affichent sur la page Rechercher. Elle fonctionne hors ligne, même en ouvrant le site depuis le disque ; un mot est cherché avec ses variantes de terminaison (« générer » trouve « généré »).

  • Diagrammes : dessinés au moment de la génération, avec leur texte alternatif et leur description complète dépliable ; le site n'a plus besoin de Mermaid.

  • Bouton Copier sur chaque bloc de code.

  • Plan du site (obligatoire RGAA) : généré d'après le menu, avec les pages hors menu, et lié dans le pied de page ; une page plan-du-site.md du site le remplace.

  • Page 404 (adresse introuvable), sitemap.xml et robots.txt pour les moteurs de recherche (il faut l'adresse publique dans site-config.md).

  • Redirections : pour chaque ligne de redirections, une petite page à l'ancienne adresse renvoie vers la nouvelle.

Rapport avant publication

Le bouton Rapport avant publication du bandeau Site génère le site et liste ce qui est à revoir avant de le mettre en ligne :

  • contrôles du site : lien vers la déclaration d'accessibilité et vers les mentions légales dans le pied de page (obligatoires), page d'accueil, adresse publique, titres de page en double (chaque page doit avoir un titre qui la distingue, RGAA 8.6) ;
  • accessibilité de chaque page (les points du bouton Accessibilité) ;
  • liens cassés et liens mal formés, images manquantes ;
  • images lourdes (plus de 500 Ko, elles ralentissent les pages sur mobile), de la plus lourde à la plus légère ;
  • images inutilisées du dossier images : elles ne sont pas publiées ; un clic les range dans images/non-utilisees.

Chaque ligne qui concerne une page l'ouvre d'un clic. Publier… fait ce rapport d'abord : s'il y a des points à voir, il s'affiche avec le bouton Publier quand même.

Historique d'une page

Chaque enregistrement garde une version du document (avec la sauvegarde automatique : une toutes les 5 minutes au plus), 60 au plus par document. Historique (icône en haut à droite, ou Fichier) les liste de la plus récente à la plus ancienne. Choisissez-en une : ses différences avec le texte actuel s'affichent ligne à ligne, en rouge ce qui a été retiré depuis, en vert ce qui a été ajouté. Restaurer cette version la remet dans l'éditeur ; enregistrez pour la garder. Le texte d'avant la restauration est lui-même gardé dans l'historique : une restauration s'annule en restaurant la version précédente.

Les versions sont rangées dans le dossier de l'application, pas à côté du document : elles ne sont ni publiées avec le site, ni partagées. Elles restent sur cet ordinateur.

Orthographe

Le bouton Orthographe (barre de mise en forme, après Rechercher ; ou Outils → Orthographe) souligne en rouge les mots mal orthographiés pendant la frappe. C'est le correcteur du système : sur Mac, celui de macOS, qui reconnaît la langue du texte (le français doit faire partie des langues du Mac, Réglages Système → Général → Langue et région) ; sous Windows, celui de Windows. Un clic droit sur un mot souligné propose les corrections, et permet d'apprendre un mot (nom propre, sigle). Le correcteur ne vérifie que l'orthographe des mots, pas la grammaire ni les accords : « je suis contant de vous voire » n'est pas signalé.

Rechercher dans le site

Le bouton Rechercher dans le site du bandeau Site cherche un mot ou une expression dans toutes les pages (métadonnées comprises). Options : Respecter la casse, Mot entier, Expression régulière, et Ignorer les adresses, cochée par défaut : les adresses des liens et des images ne sont ni cherchées ni remplacées, pour ne pas les casser.

Les résultats sont groupés par page, avec la ligne et le mot surligné ; un clic ouvre la page sur la ligne. Pour remplacer, écrivez le nouveau texte dans Remplacer par, décochez les pages à laisser telles quelles, puis Remplacer. Tant que la boîte reste ouverte, Annuler le remplacement remet les pages dans leur état d'avant.

Nouvelle page et modèles

Le bouton Nouvelle page du bandeau Site crée une page d'après un modèle :

  • Page vide : titre et métadonnées ;
  • Tutoriel : ce qu'il faut avant de commencer, des étapes numérotées avec capture d'écran et alertes, puis « En cas de problème » en accordéons ;
  • Foire aux questions : questions en accordéons, rangées par thème ;
  • Actualité : chapeau en mise en avant, image, « Ce qui change », « Ce que vous avez à faire », « En savoir plus ».

Le nom du fichier est tiré du titre (« Réserver une salle » donne reserver-une-salle.md), sauf si vous l'écrivez. La page peut être ajoutée au menu, dans la rubrique choisie ; elle s'ouvre ensuite, prête à remplir. Les images du modèle sont à remplacer : le rapport avant publication les signale tant qu'elles manquent.

Organiser le menu et renommer une page

Le bouton Organiser le menu du bandeau Site montre le menu en arbre. Faites glisser une entrée au-dessus ou en dessous d'une autre, ou sur le milieu d'une entrée pour en faire une sous-page. Au clavier, chaque entrée a ses boutons Monter, Descendre, Retrait (sous-page de l'entrée du dessus), Sortir du retrait et Retirer du menu. Les libellés se modifient directement ; la liste du bas ajoute une page hors menu, et Nouvelle rubrique une ligne sans lien. Enregistrer le menu réécrit site-menu.md (le texte d'introduction est gardé).

Pour renommer une page du site, cliquez son nom en haut, après les espaces. Les liens des autres pages, le menu et le fil d'Ariane sont mis à jour, et l'ancienne adresse est ajoutée aux redirections de site-config.md : les liens déjà publiés vers l'ancienne page continuent de marcher.

Aperçu en direct

Le bouton Aperçu en direct du bandeau Site ouvre le site dans votre navigateur, sur la page en cours. À chaque enregistrement (y compris la sauvegarde automatique), la page est refaite dans www et le navigateur la recharge tout seul : écrivez d'un côté, regardez le résultat de l'autre. Les fichiers site-config.md, site-menu.md et site-footer.md régénèrent tout le site, puisqu'ils changent toutes les pages.

Le site est servi par l'application elle-même, à une adresse locale (http://127.0.0.1:…) que seul votre ordinateur voit. La recherche du site et les menus des autres pages se mettent à jour à la prochaine génération complète (Générer le site).

Publier le site

Le bouton Publier… du bandeau Site génère le site, puis le met en ligne. La boîte demande :

  • l'hébergeur : le GitLab de la forge, gitlab.com, un autre serveur GitLab, ou GitHub ;
  • le projet : groupe/nom ou prenom.nom/nom ; il est créé s'il n'existe pas ;
  • la branche (main) et le jeton d'accès. Sur GitLab, le jeton se crée dans Préférences → Jetons d'accès, avec la portée « api ». Il est rangé dans le trousseau du système (Trousseau d'accès sur Mac), jamais dans le site ; Oublier le jeton l'en retire.

Sur GitLab, le projet est privé : les pages Markdown et les images y sont rangées (case à cocher), et seul le dossier www est mis en ligne par GitLab Pages, visible de tous. Le fichier .gitlab-ci.yml est ajouté à la première publication ; s'il est modifié à la main, il est gardé.

Sur GitHub (gratuit), un dépôt privé ne peut pas publier de site. Le dépôt du site est donc public et ne contient que le site, sans les sources ; un second dépôt, privé et facultatif, reçoit les pages Markdown.

Seuls les fichiers modifiés depuis la dernière publication sont envoyés, par lots ; une publication interrompue reprend là où elle s'est arrêtée. La mise en ligne prend une à deux minutes : un message donne l'adresse du site quand elle est faite.

Au premier envoi après une mise à jour de l'application, le Mac peut demander l'autorisation d'utiliser le jeton rangé dans le trousseau : répondez Toujours autoriser.
