Télécharger

Dernière version

  • Mac (Apple Silicon) : Markdown-office_1.38.6_aarch64.dmg
  • Windows (x64) : Markdown-office_1.38.6_windows_x64-setup.exe

Mac

Pour les Mac à puce Apple (M1 et suivants) : fichier .dmg. Ouvrez-le et glissez Markdown office dans le dossier Applications.

Windows

Fichier …_windows_x64-setup.exe : lancez-le et suivez l'installation.

Mises à jour

Quand une nouvelle version est publiée, la barre du bas de l'application affiche « Version x.y disponible » : un clic montre les nouveautés, puis Installer et redémarrer. Le détail est dans les Nouveautés.

Toutes les versions : releases du projet.
